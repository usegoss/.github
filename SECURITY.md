# Security policy

This policy covers every repository in the [usegoss](https://github.com/usegoss) organization.

## Reporting a vulnerability

Do not open a public issue, discussion, pull request, or social post about a security problem.

Report privately in either of these ways:

- Open a private security advisory in the affected repository (Security tab → Advisories → Report a vulnerability).
- Email <security@usegoss.com>.

If you are a Goss team member, use the affected repository's Security tab so the advisory, the fix, and the disclosure stay with the code. Do not use the `support@` or `contact@` addresses for vulnerabilities.

Include the affected surface, the version or commit, a description of the issue, and reproduction steps or a proof of concept if you have one.
