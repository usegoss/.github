# Goss

Goss is a language app for learners who already know the basics. Bring a link, a feed, or a video — or find something inside Goss — and it becomes an interactive story you can read, hear, and talk about.

- Website: <https://www.usegoss.com>
- Support: <support@usegoss.com>
- Security: <security@usegoss.com>

This organization hosts the Goss product, its infrastructure, and the shared engineering tooling that builds and ships it.

## Contact

| I need to… | Contact |
| --- | --- |
| Get help with the app, my account, or billing | <support@usegoss.com> |
| Report a security vulnerability | Do not open an issue. Follow the [security policy](https://github.com/usegoss/.github/blob/main/SECURITY.md) or email <security@usegoss.com> |
| Work on a change, bug, or improvement | The repository that owns the surface, not this one |

Goss does not accept outside issue reports or contributions. If you are not a
Goss team member, email <support@usegoss.com> and we will route it.

## For Goss team members

- Work in the repository where the change lives.
- File bugs, epics, and stories in that repository's issue chooser so the
  matching issue type is set. Use a Story or Epic instead of a Feature. Task
  work has no form; create a blank issue when you need one.
- Use this `usegoss/.github` repository only for defaults that must apply to
  every repository.
